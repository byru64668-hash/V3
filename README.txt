SCHOOLTRACK — EAPIHS SCHOOL INVENTORY SYSTEM

This is the SchoolTrack offline inventory web app for EAPIHS school use only.

FILES
- index.html — main application
- app.js — inventory functions and data storage
- style.css — Maroon + Green design
- manifest.json — app installation settings
- service-worker.js — offline caching
- click.mp3 — button click sound
- icon-512.svg — app icon

HOW TO USE WITH GITHUB PAGES
1. Upload all files in this folder to the ROOT of your SchoolTrack GitHub repository.
2. Make sure index.html is directly in the repository root.
3. Open Settings > Pages.
4. Select Deploy from a branch, choose main and / (root), then Save.
5. Open the published SchoolTrack site.
6. In Chrome, choose Add to Home screen to use it like an app.

IMPORTANT
This ZIP is a web/PWA project, not an Android APK. It cannot be installed by tapping the ZIP.
Inventory data is stored locally on the device/browser. Keep regular backups.
